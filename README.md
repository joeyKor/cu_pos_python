# 🏪 DU Retail POS System (Python/PyQt6)

이 프로젝트는 Python과 PyQt6를 활용하여 구현된 대구대학교(DU) 스타일의 스마트 소매점 POS(Point of Sale) 시스템입니다. 직관적인 사용자 인터페이스와 다양한 결제 모듈, Tmoney 교통카드 스캐너 연동 및 잔액 관리, 금전문함(돈통) 하드웨어 제어, **코코아톡(CocoaTalk) 메신저 연동 모바일 상품권 발급/전송 시스템**, 그리고 Firebase Firestore를 통한 클라우드 동기화 및 로컬 백업(Mock DB) 시스템을 지원합니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 시작 및 대기 화면 (Welcome Page)
* **DU 마스코트 & 배너**: DU 브랜드 아이덴티티가 강조된 고해상도 그래픽과 깔끔한 대기화면을 제공합니다.
* **직전 결제 내역 확인**: 가장 최근에 완료된 결제 금액, 받은 금액, 거스름돈을 메인 화면에서 한눈에 파악할 수 있습니다.
* **금고 잔액 관리 (Cash Drawer)**: 실시간 현금 거래를 자동으로 반영하여 금고 내 현금 잔액을 실시간 표시합니다. 금액 표시 부분을 더블클릭하여 실제 시설 금액으로 수동 조정할 수 있습니다.
* **즉각적인 바코드 등록**: 대기 화면에서 바코드를 스캔하거나 입력창에 5자리 상품 코드를 입력하면 즉시 판매 화면으로 전환되어 상품이 등록됩니다.

### 2. 판매 및 상품 등록 (Sales Screen)
* **실시간 상품 추가 및 수량 조절**: 바코드 스캔 또는 수동 입력을 통한 실시간 테이블 상품 추가, 수량 변경 및 개별/전체 삭제 기능.
* **행사 상품 및 할인 자동 계산**: 1+1, 2+1 행사 상품 자동 증정/할인 및 제휴 할인 기능 지원.
* **행사 상품 음성 안내 (TTS Voice Guidance)**: 1+1, 2+1 등 행사 상품 스캔 시 친절한 음성 안내 MP3가 자동 재생됩니다.
* **보관 쿠폰(키핑)**: 증정품을 매장에서 바로 수령하지 않을 시 키핑 쿠폰 바코드 발급 및 교환 지원.
* **통합 계산기 페이지**: 판매 화면 내에서 즉시 계산을 도와주는 편리한 보조 계산기 패널을 탑재하였습니다.

### 3. 모바일 상품권 관리 & 코코아톡(CocoaTalk) 메신저 연동 ☕📱
* **🎫 모바일 상품권 자동 발급**: 교환 대상 상품 선택 시 `99`로 시작하는 13자리 전용 바코드를 자동 발급하며, 상품권 명칭 및 금액을 관리합니다.
* **🖼️ 고화질 쿠폰 카드 비트맵 렌더링**: PyQt6 QPainter 엔진을 통해 상품 대표 사진, Code128 바코드 그래픽, 상품명, 금액, 교환 안내 문구가 포함된 카카오톡 선물하기 스타일의 세련된 쿠폰 카드(400x600)를 즉시 생성합니다.
* **🔍 실시간 코코아톡 회원 조회**: PocketBase BaaS(`cocoa_users` 컬렉션)와 연동하여 수신자의 **전화번호 또는 이메일**로 가입자 정보를 실시간 검색하고 확인 배지를 표시합니다.
* **🚀 1:1 대화방 즉시 전송**: DU마트 공식 계정(`dumart@cocoatalk.com`)으로 수신자와의 전용 대화방을 생성하여 쿠폰 카드 이미지(`data:image/jpeg;base64`)와 안내 텍스트를 실시간 발송합니다.
* **📲 현장 바코드 교환**: 고객이 코코아톡 앱에서 수신한 상품권 이미지를 터치하면 확대 표시되며, 매장 POS 스캐너로 스캔하여 상품으로 즉시 교환/결제할 수 있습니다.

### 4. 교통카드(Tmoney) 스캐너 연동 & 잔액 관리 시스템
* **💳 실시간 카드 스캐너(RFID / 바코드) 연동**: 스캐너를 통해 입력되는 카드 UID를 백그라운드에서 실시간으로 감지 및 식별합니다.
* **🔒 UID 비노출 보안 처리**: 카드 스캔 시 화면에 난수성 UID가 노출되지 않도록 처리하고, 세련된 Tmoney 카드 그래픽으로 시각화합니다.
* **⚡ 현금 충전**: 카드를 스캔하고 원하는 금액(+1천원, +3천원, +5천원, +1만원 등)을 선택하여 즉시 충전합니다. (엔터키 원터치 충전 지원)
* **🪙 잔액 환불**: 카드 잔액에서 대행 수수료(500원)를 차감한 후 고객에게 현금 지급하며, 금전문함(돈통)이 자동으로 오픈됩니다.
* **🔍 잔액 및 거래내역 조회**: 카드 스캔 시 현재 잔액과 함께 충전/결제/환불 상세 이력(일시, 구분, 금액, 잔액)을 표로 제공합니다.
* **🎯 상시 포커스 유지**: 스캐너 입력이 다른 입력 필드로 유입되지 않도록 카드 스캔 입력창에 항상 포커스를 유지합니다.

### 5. 강력하고 다양한 결제 모듈 (Multi-Payment System)
* **💳 신용카드 결제**: 카드 번호 입력 및 IC 칩/MS 결제 시뮬레이션 지원.
* **💵 현금 결제**: 받은 금액 입력 시 거스름돈 자동 계산 및 금전문함 자동 오픈, 현금영수증 발행 팝업 연동.
* **🚌 Tmoney(교통카드) 결제**: 티머니 카드를 스캔하여 상품 대금을 즉시 결제하며, 결제 완료 후 **국세청 현금영수증(소득공제/지출증빙) 발행 팝업**이 자동 호출됩니다.
* **📱 모바일 간편결제 & 상품권**: 네이버페이, 카카오페이, 모바일 교환권/상품권 바코드 결제 처리.
* **📝 외상/후불 결제**: 후불 거래 내역 관리 및 정산 기능 지원.
* **💰 거스름돈 적립**: 거스름돈 발생 시 고객 포인트/계좌로 적립하는 서비스.

### 6. 하드웨어 및 부가 서비스
* **🗄️ 금전문함(Cash Drawer) 하드웨어 제어**: 시리얼 포트(COM) 통신을 통해 현금 결제 및 환불 시 자동으로 금전함 오픈 신호 전송.
* **📦 무인 택배 접수 (Parcel Service)**: 주소 검색, 무게 측정 시뮬레이션, 운송장 출력 풀 프로세스 지원.
* **🔄 환불 및 반품 (Refund)**: 영수증 번호 조회를 통한 즉시 환불 및 취소 처리.
* **📑 영수증 관리 & 인쇄**: 영수증 상세 조회 및 HTML/텍스트 영수증 출력 뷰어 지원.

### 7. 데이터 영속성 및 동기화 (Data Persistence)
* **Firebase Firestore 연동**: 실시간으로 클라우드 데이터베이스에 상품 및 거래 내역을 동기화합니다.
* **로컬 Mock DB 지원**: `json/firebase_credentials.json` 파일이 없거나 오프라인 상태일 경우 자동으로 로컬 JSON 데이터베이스를 사용하는 완벽한 오프라인 폴백(Fallback) 시스템.

## 🛠 기술 스택 (Tech Stack)

* **Programming Language**: Python 3.13
* **GUI Framework**: PyQt6 (POS 메인 화면), Tkinter (IC 카드 읽기/쓰기 유틸리티)
* **Database & Cloud**:
  - Firebase Firestore (온라인 클라우드 DB) & Local JSON (오프라인 폴백)
  - PocketBase BaaS (코코아톡 메신저 실시간 회원 조회 및 메시지 전송 API)
* **Hardware Integration**:
  - RFID / 바코드 리더기 (HID 키보드 웨지 방식 스캐너)
  - 시리얼 금전문함 (pySerial 기반 COM 포트 오픈 신호 전송)
  - smartcard (`pyscard` 패키지를 이용한 IC 스마트카드 APDU 통신)
* **Network & API**: `requests` (PocketBase REST API 통신)
* **Barcode Generation**: `python-barcode` (Code128 바코드 렌더링)
* **Sound Effects**: Pygame Mixer / Windows Beep (바코드 인식, 행사 안내 음성, 결제 완료 알림음)

## 🚀 설치 및 실행 방법 (Installation & Run)

### 1. 요구 사항 패키지 설치
```bash
pip install PyQt6 firebase-admin pygame pyscard pyserial requests python-barcode
```

### 2. POS 프로그램 실행
```bash
python main.py
```

### 3. 모바일 상품권 및 코코아톡 전송 가이드
1. **상품권 등록**: **[설정/관리] ➔ [모바일 상품권 관리]** 진입 후 교환 대상 상품을 선택하면 전용 바코드(`99...`)가 자동 부여됩니다.
2. **미리보기**: **[상품권 이미지 보기]**를 통해 모바일 쿠폰 카드 레이아웃을 확인합니다.
3. **코코아톡 전송**: **[☕ 코코아톡 전송]**을 클릭하고 수신자의 전화번호(예: `010-1234-5678`) 또는 이메일을 입력한 후 **[회원 조회]**를 누릅니다.
4. 가입자 확인 배지가 표시되면 **[☕ 코코아톡으로 전송하기]**를 눌러 쿠폰 카드 사진을 실시간 발송합니다.
5. 수신자는 코코아톡 앱에서 상품권을 확인하고, 계산대에서 바코드를 스캔하여 결제/교환할 수 있습니다.

### 4. Tmoney 교통카드 기능 사용 가이드
1. **충전**: 메인 화면에서 **[교통카드] ➔ [교통카드 충전]** 진입 후 스캐너로 카드를 인식하고 충전 금액을 선택합니다.
2. **환불**: **[교통카드] ➔ [교통카드 환불]** 진입 후 카드를 스캔하면 잔액에서 수수료 500원을 제외한 금액이 정산되며 금전함이 자동으로 열립니다.
3. **조회**: **[통합조회] ➔ [교통카드잔액조회]** 진입 후 카드를 스캔하여 잔액 및 최근 거래 내역을 확인합니다.
4. **결제**: 상품 등록 후 **[결제선택] ➔ [교통카드]**를 선택하여 카드를 스캔하면 잔액 차감 결제가 진행되며, 완료 즉시 **현금영수증 발행 팝업**이 나타납니다.
